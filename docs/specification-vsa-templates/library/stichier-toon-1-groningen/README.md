Stichiermelodie toon 1 (Groningen). Liturgisch kan het stuk een andere
`soort` hebben; zet dan `formule: stichier` in de VSA-frontmatter (T1).

**Corpus** (`examples/corpus/`) — alleen Heer-ik-roep (twee coupletten);
herzien wanneer er meer bronmateriaal is.

| Bestand                         | Strofen | Speelplan                                  |
| ------------------------------- | ------- | ------------------------------------------ |
| `heer-ik-roep-toon-1-deel1.vsa` | 6       | triple-close → 1,2,3,2,voorlaatste,laatste |
| `heer-ik-roep-toon-1-deel2.vsa` | 5       | standard → 1,2,3,2,laatste                 |

`laatste` begint op sol (c) met slotmelisma (`l.lgr.`) op de laatste
lettergreep. Cycle-frasen 1–3 zijn voorlopig alleen recite + slotcadens.
