Stichiermelodie toon 6 (Groningen). Liturgisch kan het stuk een andere
`soort` hebben (bijv. kondak); zet dan `formule: stichier` in de
VSA-frontmatter (T1).

Vroeg uit de herhaling (niet-veelvoud van 3) is toegestaan: zie
[mapping-vsa.md](../../mapping-vsa.md). Leesbare speelplan-uitleg op de
site: bibliotheek `catalogus/formules/stichier-toon-6-groningen/`.
