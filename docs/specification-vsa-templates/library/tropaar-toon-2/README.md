# tropaar-toon-2

Alias van [kondak-toon-2](../kondak-toon-2/) (`same_as`). Groningen
tropaar én kondak zondag toon 2 delen dezelfde SATB-formule (`do=F4`).

**Let op bij VSA:** na een mi-cadens (frase 1) begint frase 2 met onge-scoped
`Gij` op mi — niet `{\Gij}` (dat daalt naar re; dat patroon hoort bij toon 1,
waar frase 1 op fa eindigt).
