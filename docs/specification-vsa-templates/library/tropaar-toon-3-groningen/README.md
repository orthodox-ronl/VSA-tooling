Géén herhalingsblok: het blad noemt een vaste volgorde van secties plus
`laatste`. Bij *n*+1 VSA-frasen volgen de eerste *n* het prefix van dat
speelplan; de allerlaatste frase altijd op `laatste`. Voorbeeld: 6 frasen →
`1, 3, 1, 2, 3, laatste`. Meer dan 8 frasen is een harde fout.

Ook voor kondak toon 3 (zelfde formule via T1/alias). Referentie-MVSA:
bibliotheek `content-source/input/_klaar_voor_acceptatie/kondak-zondag-toon-3-groningen.mvsa`.
