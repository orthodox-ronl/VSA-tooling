# Source Sans 3 (latin) voor OSMD-SVG

WOFF2-bestanden van [Fontsource Source Sans 3](https://www.npmjs.com/package/@fontsource/source-sans-3)
via jsDelivr. Zelfde lyric-font als MuseScore Style / bibliotheek-scherm.

Gebruikt door `render.mjs` (laden vóór OSMD) en als `@font-face` in de
uitvoer-SVG, zodat lyrics niet op Times New Roman terugvallen.
