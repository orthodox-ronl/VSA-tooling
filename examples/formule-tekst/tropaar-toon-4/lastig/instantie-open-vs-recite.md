# Instantie — recite zonder apart “open”-slot (blok `f1`)

|       |                                                                  |
| ----- | ---------------------------------------------------------------- |
| Tekst | [`tekst-frase1-open-recite.ftxt`](tekst-frase1-open-recite.ftxt) |
| Blok  | `f1`                                                             |

## Wat de formule nu doet

```text
S: a - @l.st._ /_ \_ |
```

- `a -` … tot `@l.st.` = **recite** (één slot; export mag 1-n-1 printen)
- Geen `[open]`: wat op het toonboek als openingsnoot + box oogt, is
  recite-conventie, geen tweede bron-event
- Optioneel (`a?`) is voor **andere** slots (zie blok `f2`), niet hiervoor

## Tekst

`Als de Re'gel des ge'loofs` → lettergrepen op de recite-toon tot `ge'loofs`
als `@l.st.`, daarna cadens `/_` `\_`.
